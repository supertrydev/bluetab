# Security policy

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Report them privately in one of these ways:

- Email **support@supertry.net** with "Security" in the subject line.
- Use GitHub's [private vulnerability reporting](https://github.com/supertrydev/bluetab/security/advisories/new).

Please include:

- What you found and where (file, feature, or URL).
- Steps to reproduce, and the browser and Bluetab version.
- What an attacker could do with it.

We reply within 3 working days, keep you updated while we fix it, and credit
you in the release notes unless you prefer to stay anonymous.

## Supported versions

Only the latest version in the Chrome Web Store and Firefox Add-ons receives
security fixes.

## Scope

In scope: the Bluetab browser extension in this repository.

The Supertry account, sync, AI and sharing services (supertry.net, bluet.in)
are not in this repository, but reports about them are welcome at the same
address.
